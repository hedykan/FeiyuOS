# 人工验收

自动 E2E（`tools/vat_e2e.py`）经设备 Web API 驱动，覆盖了运行时、SSH、tmux、多步任务、密钥、页面状态、取消和重启恢复。下面这些只能由人在实物上确认，每次发布前做一遍。界面效果可以先用 `http://<设备 IP>/api/screenshot` 截图对照。

## 准备

- 拔掉 USB，只用电池供电（或只接充电头，不接电脑）。
- 测试会在远端新建 `vat-*` 开头的 tmux 会话，不影响已有会话。

## 步骤

| # | 操作 | 预期 |
|:--|:--|:--|
| 1 | 开机 | 进入 Agent 页：顶栏是“Agent SSH”、主机名、WiFi 信号；时间线显示最近的对话（时间正确，联网对时） |
| 2 | 按住 `Enter` 说“在开发机看下磁盘还剩多少”，松开 | 录音时底部有红点、跳动的音量条、秒数；松开后新增一行，进度依次走“识别 · 理解 · 执行 · 总结”；完成后显示 ✓ 和一句结论，≤10 s |
| 3 | `;` `.` 移动，`/` 打开详情，`,` 返回 | 选中行高亮并展开结论；详情页显示原话、结论、执行的命令和原始输出，`;` `.` 能滚动 |
| 4 | 说“在开发机创建目录 /tmp/vat-manual，然后在里面新建 a.txt 内容是 hi” | 第一步时这一行变橙色，显示命令和“Y 执行 N 取消 A 后续都执行”；按 `Y` 后自动走到下一步再次等待；再按 `Y` 完成；远端文件存在 |
| 5 | 同样的话再说一次（换个目录），第一步按 `A` | 后续步骤不再询问，直接完成 |
| 6 | 再说一次，第一步按 `N` | 显示已取消，远端没有创建 |
| 7 | 说“连接 WiFi 某个附近的加密网络” | 弹出密码输入框（圆点掩码），`Fn+S` 能显示明文；按 `` ` `` 取消后仍连着原网络 |
| 8 | 说“在开发机执行 sudo whoami”，按 `Y` | 需要 sudo 密码的主机弹出输入框；输入正确后结论为 root |
| 9 | 按 `Btn0` 到 SSH 页，键盘输入 `ls` 回车 | 终端显示结果；`Tab`、`Ctrl+C`、`` ` `` 分别生效；顶栏显示“开发机 · vat-shell”和绿点 |
| 10 | SSH 页输入 `sudo -k; sudo true` 回车 | 出现密码提示后，底部变成橙色“远端在等密码”，输入显示为 `*`，回车后命令完成 |
| 11 | SSH 页按住 `Fn+Enter` 说一句话 | 变成草稿，不自动发送；`Enter` 才发送 |
| 12 | 说一句较长的指令，在“理解”阶段按 `` ` `` | 这一行显示已取消，2 s 内可以继续使用 |
| 13 | `Fn+H` 翻三页 | 第 2 页显示亮度、息屏、音量、WiFi、主机等当前值和示例说法；第 3 页显示能做的事 |
| 14 | `Fn+Tab` 切到只转写，按住 `Enter` 说话 | 时间线新增一行，只有转写，不执行 |
| 15 | 断电再开机 | 时间线保留重启前的记录；问“我们刚才操作的是哪台主机？”回答正确 |
| 16 | 连续使用 20 次 | 无重启、无卡死；`/api/status` 中 `reset_reason` 不是 panic/task_wdt |
| 17 | `Fn+W` 打开设置页，选“手机设置（扫码）”，手机扫第一个码 | 手机加入 `VAT-XXXX` 热点后自动弹出设置页（不弹时扫屏幕上的第二个码）；在手机上改字号，设备提示“手机已修改” |
| 18 | 说“响两声” | 扬声器响两声，不需要确认 |
| 19 | 对着电视说“用红外打开客厅电视” | 发码后时间线询问是否生效；没反应答“没反应”会换下一组码，生效后答“生效”，下次直接用这组码 |
| 20 | 说“十秒后提醒我喝水” | 10 秒后全屏提醒并响三声，任意键关闭 |
