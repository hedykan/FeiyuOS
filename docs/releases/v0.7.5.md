肥鱼 OS v0.7.5：不闪屏的屏幕、完整的 gfx 画图。所有画面先在内存里画好再整条推上屏，切页、滚动、动画、面板刷新都不再闪；程序里可以用 M5GFX 的绘图函数（同名同参）逐帧画画面和动画，大肥鱼也会自己写这样的程序。

## 新增

- **屏幕不闪**：切页、滚动、动画、面板定时刷新，都不会再看到底色闪一下或形状一个个冒出来；内容没变的地方不重画，也更省电。
- **画图更完整**：程序开头写 `-- @uses gfx`，就能用 M5GFX 的 76 个绘图函数（名字和参数都一样）：形状、抗锯齿线、渐变、文字和字体、位图、PNG/JPG/BMP 图片、二维码……画完一帧 `gfx.present()` 上屏，每秒能到二三十帧。全部函数和例子对大肥鱼说「看看 gfx 有哪些函数」或 `read gfx://help`。
- **让大肥鱼画**：「写个程序画一个来回弹的小球」「在屏幕上画一个时钟」，它会自己写出画图程序并运行。
- **详细页实时步骤**：任务进行中按 `/` 打开记录详细页，每一步（调用了什么、等待确认、结果）都会实时出现，停在底部时自动跟着滚；结束后再看也是同样的步骤。
- **显示思考**：设置页新增「显示思考」（默认关）。打开后大肥鱼先想一想再回答，想法显示在详细页；会稍慢一点，个别指令会先多读一步再动手。也可以直接说「打开显示思考」。
- **画布换了地址**：画布从 `ui://canvas/名字` 改为 `gfx://canvas/名字`，卡上已保存的会自动改写。

## 修正

- 设备用久了、对话历史多了以后，让大肥鱼「翻翻以前查过的」会占用过多内存；现在只读需要的几条。

## 已知的限制

- 「让 Claude 检查一下项目」这类没说哪个项目的话，大肥鱼有时不先问清楚就去启动，会因为找不到项目而失败一次再来问你（0.7.4 起就有，下个版本修）。
- 读取屏幕已有像素、填充封闭区域、离屏画布（sprite）这几类函数还没有，留到 0.8 独占态。
- 单个程序约 7 KB 源码仍是上限；一帧最多 64 条绘制指令，位图和图片合计 32 KB。
- 录音偶尔会停在约 0.4 秒（v0.7.2 起就有，原因还在查）；遇到时把电池开关关掉、拔掉 USB 断电一次可以恢复，请告诉我们。
- 电池开着又插着 USB 时，TF 卡在大量写入时可能超时，最坏会写坏卡上的文件系统。长时间插着电脑跑任务时，建议把电池开关关掉。

## 刷写

```sh
pip install esptool
# 首次安装和升级都是这一条
esptool --chip esp32s3 --port /dev/ttyACM0 --baud 921600 write_flash 0x0 feiyuos-v0.7.5-cardputer-adv.bin
```

Windows 上端口一般是 `COMx`，macOS 上是 `/dev/cu.usbmodem*`。刷写不会动 TF 卡和板载存储分区，设备上的配置、程序和对话记录都还在。这个版本只在 GitHub 发布，M5Burner 上仍是 v0.7.1。

从 v0.7 ~ v0.7.4 升级只需刷固件，卡上资源没有变化。第一次开机会把卡上已保存的程序、应用里的 `ui://canvas/` 改成 `gfx://canvas/`（只做一次）；从 v0.7.3 及更早升级时，0.7.4 的地址改写也会一并完成，见 [v0.7.4 的说明](https://github.com/hedykan/FeiyuOS/releases/tag/v0.7.4)。从 v0.6 及更早升级，先看 [v0.7 的说明](https://github.com/hedykan/FeiyuOS/releases/tag/v0.7)（程序改用 Lua，旧 JSON 程序需要翻译）。

## 拷卡上资源

`sd.zip` 里只有 `vat/` 下的资源文件，解压到卡上只会新增或替换这几个文件，卡上原有的配置、程序和对话记录不受影响：

```sh
# macOS（卡名按实际改）/ Linux
unzip -o feiyuos-v0.7.5-sd.zip -d /Volumes/卡名
```

Windows：右键「全部解压缩」，目标选 TF 卡根目录。**macOS 不要用访达把 `vat` 文件夹直接拖到卡上**：遇到同名文件夹时访达默认是「替换」，会删掉卡上原有的 `vat`；要拖的话按住 Option 选「合并」。

## 第一次开机

固件里**不含任何 Key**。开机后进入设置页，同时开热点 `VAT-XXXX`：

1. 选 Wi-Fi、输入密码（只支持 2.4 GHz）。也可以在设置页选「手机设置（扫码）」，用手机填。
2. 填 Key（设置页「Key」，或手机扫码填）。**必需的只有前两个**，可选的不填也能用，只是少了对应功能：
   - **语音识别 Key（千问）**，必需：[阿里云百炼](https://bailian.console.aliyun.com/)开通模型服务，在「API-KEY」页创建，选北京地域。
   - **Agent Key（DeepSeek）**，必需：[DeepSeek 开放平台](https://platform.deepseek.com/)注册、充值，在「API keys」页创建。
   - **高德 Key**，可选（不填只是不能查位置、附近、天气、路线）：[高德开放平台](https://console.amap.com/)创建应用、添加 Key，服务平台选「Web 服务」。
   - **接口令牌**，可选（比如 GitHub），不用事先填：第一次用时设备会弹出输入框，令牌只发给那个网站。
3. 建议插一张 TF 卡：程序、扩展包、长对话、完整输出、空调码库、开机动画和吉祥物都存在卡上。

Key、Wi-Fi 密码和接口令牌以明文保存在设备上，只在可信网络里使用，见 [SECURITY](https://github.com/hedykan/FeiyuOS/blob/main/SECURITY.md)。
