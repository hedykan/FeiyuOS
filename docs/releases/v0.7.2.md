肥鱼 OS v0.7.2：让大肥鱼写程序这件事变得可靠——程序能写完，运行结果它看得懂，出了错知道怎么改，改的时候不用整份重写，事后能查每次运行的输出。

## 新增

- **程序能写完了**：以前模型每轮最多输出 700 token，稍长的程序写到一半就被截断。现在每轮 4000 token、一个任务 10 轮，几百行的程序可以一次写完、运行、出错再改。实测在设备上写一个 6 KB 的两模块程序约半分钟。
- **出错知道怎么改**：工具结果的第一行写明「已执行」还是「失败」；失败的结果末尾带「怎么改」。程序出错时会指出是第几行、那一行的源码和调用栈。
- **只改一部分**：对大肥鱼说「把 xx 程序里的 yy 改成 zz」，它用补丁只改那几行（`write prog://名字/patch`），也可以只看程序的一段（`?grep=`、`?lines=`）。
- **查之前的运行**：「昨晚的定时程序为什么失败了」「刚才那个程序输出了什么」。每次程序运行的输入、输出、错误都记在卡上的三条流里（`read debug://stdout`、`debug://stderr`、`debug://stdin`、`debug://run/编号`）。
- **程序里更好写**：`vat.read("device://local/battery")` 直接得到 `{percent, voltage, usb}`，SSH 命令得到 `{stdout, stderr, code}`，不用再从一句话里抠数字；`print` 一个表会显示它的内容；`vat.log` 带时间、不占输出；新增 `vat.now()`。按文字结果写的旧程序不用改。
- **少反问**：「把灯打开」「写个程序」这类话直接按本机的灯、本机的 Lua 程序去做；提到的东西不确定有没有时先查设备，不先问你。
- **程序页**：列表按最近使用排序，`Del` 删除（要按 `Y` 确认），按住 `;` `.` 连续移动，选中行绿色文字。

## 修正

- 6 KB 左右的程序报内存不够（实际是内存碎了要不到整块）；卡上程序多时偶尔重启；写程序时内存被压得很低；模型回复偶尔只收到一半；进程序页时 Agent 页的底栏残留在屏幕上。

## 已知的限制

- 单个程序约 7 KB 源码是上限（Lua 虚拟机 48 KB）。程序之间不共用数据，所以更大的功能还不能靠拆成几个程序来做。
- 写 6 KB 的程序时空闲内存余量很小（最低到过十几 KB）。下一个版本专门处理内存。
- 设备的时间没对上时，运行记录里的时间显示为 `--:--`。

## 刷写

```sh
pip install esptool
# 首次安装和升级都是这一条
esptool --chip esp32s3 --port /dev/ttyACM0 --baud 921600 write_flash 0x0 feiyuos-v0.7.2-cardputer-adv.bin
```

Windows 上端口一般是 `COMx`，macOS 上是 `/dev/cu.usbmodem*`。刷写不会动 TF 卡和板载存储分区，设备上的配置、程序和对话记录都还在。这个版本只在 GitHub 发布，M5Burner 上仍是 v0.7.1。

从 v0.7、v0.7.1 升级只需刷固件，卡上资源没有变化；卡上已有的程序不用改。从 v0.6 及更早升级，先看 [v0.7 的说明](https://github.com/hedykan/FeiyuOS/releases/tag/v0.7)（程序改用 Lua，旧 JSON 程序需要翻译）。

## 拷卡上资源

`sd.zip` 里只有 `vat/` 下的资源文件，解压到卡上只会新增或替换这几个文件，卡上原有的配置、程序和对话记录不受影响：

```sh
# macOS（卡名按实际改）/ Linux
unzip -o feiyuos-v0.7.2-sd.zip -d /Volumes/卡名
```

Windows：右键「全部解压缩」，目标选 TF 卡根目录。**macOS 不要用访达把 `vat` 文件夹直接拖到卡上**：遇到同名文件夹时访达默认是「替换」，会删掉卡上原有的 `vat`；要拖的话按住 Option 选「合并」。

## 第一次开机

固件里**不含任何 Key**。开机后进入设置页，同时开热点 `VAT-XXXX`：

1. 选 Wi-Fi、输入密码（只支持 2.4 GHz）。也可以在设置页选「手机设置（扫码）」，用手机填。
2. 填 Key（设置页「Key」，或手机扫码填）。**必需的只有前两个**，可选的不填也能用，只是少了对应功能：
   - **语音识别 Key（千问）**，必需：[阿里云百炼](https://bailian.console.aliyun.com/)开通模型服务，在「API-KEY」页创建，选北京地域。
   - **Agent Key（DeepSeek）**，必需：[DeepSeek 开放平台](https://platform.deepseek.com/)注册、充值，在「API keys」页创建。
   - **高德 Key**，可选（不填只是不能查位置、附近、天气、路线）：[高德开放平台](https://console.amap.com/)创建应用、添加 Key，服务平台选「Web 服务」。
   - **接口令牌**，可选（比如 GitHub），不用事先填：第一次用时设备会弹出输入框，令牌只发给那个网站。
3. 建议插一张 TF 卡：程序、扩展包、长对话、完整输出、空调码库、开机动画和吉祥物都存在卡上。

Key、Wi-Fi 密码和接口令牌以明文保存在设备上，只在可信网络里使用，见 [SECURITY](https://github.com/hedykan/FeiyuOS/blob/main/SECURITY.md)。
