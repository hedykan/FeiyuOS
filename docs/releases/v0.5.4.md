肥鱼 OS v0.5.4：能遥控空调了，等待中的程序可以中途取消，设置页的 WiFi 切换和搜索也修好了。

## 新增

- **空调红外**：说「把客厅空调开到 26 度制冷，奥克斯的」，之后「调高一度」「关掉」「除湿」「高风」都行。码库来自 IRext（245 个空调品牌、521 套码），放在 TF 卡上按需读取；第一次会按常用程度逐套试码，你说「生效了」或「没反应」，试对了就记住。也能写进程序和定时触发，比如每天 18 点开空调。
- **取消等待中的运行**：番茄钟这类带等待的程序启动后，可以说「把番茄钟停了」，只取消这一次，程序和定时都保留。删除程序时也会一并取消它正在等待的运行。

## 修正

- 设置页连上一个 WiFi 后切不到别的网络。
- 设置页搜索 WiFi 常常搜不到；现在会说明是「搜索失败」还是「没搜到 2.4 GHz 网络」（5 GHz 网络设备看不到）。

## 下载哪个文件

| 文件 | 用途 | 写入地址 / 卡上位置 |
|:--|:--|:--|
| `feiyuos-v0.5.4-cardputer-adv.bin` | 固件，首次安装和升级都用它（引导程序 + 分区表 + 程序；不覆盖存储分区） | `0x0` |
| `feiyuos-v0.5.4-sd.zip` | TF 卡资源：吉祥物、空调码库 | 解压到 TF 卡根目录 |
| `SHA256SUMS.txt` | 校验和 | — |

## 刷写

```sh
pip install esptool
# 首次安装和升级都是这一条
esptool --chip esp32s3 --port /dev/ttyACM0 --baud 921600 write_flash 0x0 feiyuos-v0.5.4-cardputer-adv.bin
```

Windows 上端口一般是 `COMx`，macOS 上是 `/dev/cu.usbmodem*`。刷写不会动 TF 卡和板载存储分区，设备上的配置、程序和对话记录都还在。也可以在 M5Burner 里搜「FeiyuOS」直接烧录（只有固件，卡上资源仍需解压 sd.zip）。

## 拷卡上资源

`sd.zip` 里只有 `vat/` 下的资源文件，解压到卡上只会新增或替换这几个文件，卡上原有的配置、程序和对话记录不受影响：

```sh
# macOS（卡名按实际改）/ Linux
unzip -o feiyuos-v0.5.4-sd.zip -d /Volumes/卡名
```

Windows：右键「全部解压缩」，目标选 TF 卡根目录。**macOS 不要用访达把 `vat` 文件夹直接拖到卡上**：遇到同名文件夹时访达默认是「替换」，会删掉卡上原有的 `vat`；要拖的话按住 Option 选「合并」。

## 第一次开机

固件里**不含任何 Key**。开机后进入设置页，同时开热点 `VAT-XXXX`：

1. 选 Wi-Fi、输入密码（只支持 2.4 GHz）。也可以在设置页选「手机设置（扫码）」，用手机填。
2. 填语音识别 Key（通义千问）和 Agent Key（DeepSeek）；位置服务需要高德 Key（可选）。
3. 建议插一张 TF 卡：长对话、完整输出、程序与触发、空调码库、吉祥物都存在卡上。

Key、Wi-Fi 密码以明文保存在设备上，只在可信网络里使用，见 [SECURITY](https://github.com/hedykan/FeiyuOS/blob/main/SECURITY.md)。

## 说明

- 用自建的 ESP-IDF 库编译（TLS 发送缓冲 16 KB → 4 KB，HTTPS 握手时多留出内存）。自己用官方板卡包编译也能跑，但内存余量会小一些，见 `firmware/README.md`。
- 空调码在开发机上与 IRext 自带测试程序逐段一致，奥克斯实机还在验证中；遇到没反应的品牌欢迎提 issue。
- 还没有的：蓝牙。下个版本（v0.6）做界面扩展。
