肥鱼 OS v0.7.1：v0.7 的小更新——触发可以「每隔多久」运行一次，能看到每个触发跑得怎么样，坏掉的会自己停下来、一键清理；另外加了 Wi-Fi 诊断信息。

## 新增

- **每隔多久运行一次**：对大肥鱼说「每 30 秒看一下 Codex，干完提醒我」「每 5 分钟检查一下电量」，触发可以写成 `time://every/30s`、`every/5m`、`every/2h`（最短 10 秒）。设备正忙（你在说话、在跑别的）或上一轮还没跑完时，这一轮直接跳过，不会越积越多。
- **看触发跑得怎么样**：「看看我的触发」（`read trigger://list`）会列出每个触发开机以来运行了几次、上次几点、成功还是失败、连续失败几次、忙时跳过几次。
- **坏掉的触发自己停下**：连续失败 5 次自动停用，屏幕底部提示原因；修好程序后说「重新启用 3 号触发」即可。
- **一键清理**：「清理一下失效的触发」会删掉指向已删除程序的触发和失败后停用的触发，删除前会列出来让你确认。
- **Wi-Fi 诊断**：设备开机时记录自己连的是哪个接入点（BSSID、信道、信号）和附近所有同名接入点；断线、重连都会记日志；状态接口里也能看到。局域网里连不上设备时，用它判断是不是连到了不同的路由器节点。

## 下载哪个文件

| 文件 | 用途 | 写入地址 / 卡上位置 |
|:--|:--|:--|
| `feiyuos-v0.7.1-cardputer-adv.bin` | 固件，首次安装和升级都用它（引导程序 + 分区表 + 程序；不覆盖存储分区） | `0x0` |
| `feiyuos-v0.7.1-sd.zip` | TF 卡资源：开机动画、吉祥物、空调码库 | 解压到 TF 卡根目录 |
| `SHA256SUMS.txt` | 校验和 | — |

## 刷写

```sh
pip install esptool
# 首次安装和升级都是这一条
esptool --chip esp32s3 --port /dev/ttyACM0 --baud 921600 write_flash 0x0 feiyuos-v0.7.1-cardputer-adv.bin
```

Windows 上端口一般是 `COMx`，macOS 上是 `/dev/cu.usbmodem*`。刷写不会动 TF 卡和板载存储分区，设备上的配置、程序和对话记录都还在。也可以在 M5Burner 里搜「FeiyuOS」直接烧录（只有固件，卡上资源仍需解压 sd.zip）。

从 v0.7 升级只需刷固件，卡上资源没有变化。从 v0.6 及更早升级，先看 [v0.7 的说明](https://github.com/hedykan/FeiyuOS/releases/tag/v0.7)（程序改用 Lua，旧 JSON 程序需要翻译）。

## 拷卡上资源

`sd.zip` 里只有 `vat/` 下的资源文件，解压到卡上只会新增或替换这几个文件，卡上原有的配置、程序和对话记录不受影响：

```sh
# macOS（卡名按实际改）/ Linux
unzip -o feiyuos-v0.7.1-sd.zip -d /Volumes/卡名
```

Windows：右键「全部解压缩」，目标选 TF 卡根目录。**macOS 不要用访达把 `vat` 文件夹直接拖到卡上**：遇到同名文件夹时访达默认是「替换」，会删掉卡上原有的 `vat`；要拖的话按住 Option 选「合并」。

## 第一次开机

固件里**不含任何 Key**。开机后进入设置页，同时开热点 `VAT-XXXX`：

1. 选 Wi-Fi、输入密码（只支持 2.4 GHz）。也可以在设置页选「手机设置（扫码）」，用手机填。
2. 填 Key（设置页「Key」，或手机扫码填）。**必需的只有前两个**，可选的不填也能用，只是少了对应功能：
   - **语音识别 Key（千问）**，必需：[阿里云百炼](https://bailian.console.aliyun.com/)开通模型服务，在「API-KEY」页创建，选北京地域。
   - **Agent Key（DeepSeek）**，必需：[DeepSeek 开放平台](https://platform.deepseek.com/)注册、充值，在「API keys」页创建。
   - **高德 Key**，可选（不填只是不能查位置、附近、天气、路线）：[高德开放平台](https://console.amap.com/)创建应用、添加 Key，服务平台选「Web 服务」。
   - **接口令牌**，可选（比如 GitHub），不用事先填：第一次用时设备会弹出输入框，令牌只发给那个网站。
3. 建议插一张 TF 卡：程序、扩展包、长对话、完整输出、空调码库、开机动画和吉祥物都存在卡上。

Key、Wi-Fi 密码和接口令牌以明文保存在设备上，只在可信网络里使用，见 [SECURITY](https://github.com/hedykan/FeiyuOS/blob/main/SECURITY.md)。
