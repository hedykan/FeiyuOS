肥鱼 OS v0.7：程序改用 Lua 来写，有了自己的「程序页」，可以在屏幕上看输出、用键盘输入；卡上能装扩展包，还能从在线目录一键安装和更新；大肥鱼会调网络接口了。

## 新增

- **程序用 Lua 写**：对大肥鱼说「写个程序，每天早上看天气，下雨就提醒我带伞」，它会写成一个 `.lua` 文件存在 TF 卡上（`/vat/things/lua/`）。程序要用到的能力（比如往开发机写文件）在开头声明，保存时你确认一次，以后运行就不再问。你也可以在电脑上直接改卡里的文件。
- **程序页**（Fn+A，或 Btn0 切过去）：列出卡上的程序和本地应用，回车运行。程序运行时这一页就是它的控制台——`print` 的内容实时显示，程序要你输入时底部出现输入行，按键盘左上角的 ESC 键随时中断。让大肥鱼运行程序时也会自动切过来。前台运行最长 30 分钟。
- **图形页**：程序或大肥鱼显示的大字、二维码、图片、面板、画布都在这一页，不再盖住对话；有新画面时自动切过来，看完按任意键回到原来的页面。
- **四个页面**：Btn0 在 Agent → SSH → 程序 → 图形 之间切换，左上角显示当前是哪一页。
- **调网络接口**：「查一下 arduino-esp32 在 GitHub 上的最新版本」这类请求，大肥鱼会直接发 HTTP 请求。需要令牌的接口，设备会弹出输入框让你在键盘上输入一次，令牌只会发给你录入时的那个网站。
- **卡上的扩展包**：一个带 `@package` 声明的 `.lua` 文件就是一个扩展包，启用后大肥鱼和程序都能用它。
- **在线目录**：「看看有什么可以装的」→ `read pkg://catalog`；说「安装 发布」就会下载、核对 SHA-256 和声明的权限，确认后启用；有新版本时可以更新，更新后还能退回上一版。第一个在线扩展包「发布」：查任意 GitHub 项目的最新版本号。
- **画布每帧计算**：画布可以带变量和一小段 Lua，每帧先算再画，能做跟着设备倾斜滚动的小球；最快约 30 帧/秒。
- **界面更顺**：设置页、帮助页、对话列表选择时不再闪屏，光标条和列表滚动都会平滑滑动（设置页「动画」可调成减弱或关）；Agent 页顶栏右侧可以选显示时间、电量、Wi-Fi、剩余内存等。
- **固件小了 200 KB**：中文字体换了存法，一个字都没少。

## 升级前要知道

- **原来的 JSON 程序不再运行**：它们还在卡上，`read prog://list` 会列出来，对大肥鱼说「把旧程序 xxx 翻译成 Lua」即可。原来运行程序的触发会自动迁移。
- **Fn+A** 现在打开程序页（原来的「本地应用」菜单并进了这一页）；**Btn0** 只切换页面，不再关闭画面，关闭画面按任意键。

## 下载哪个文件

| 文件 | 用途 | 写入地址 / 卡上位置 |
|:--|:--|:--|
| `feiyuos-v0.7-cardputer-adv.bin` | 固件，首次安装和升级都用它（引导程序 + 分区表 + 程序；不覆盖存储分区） | `0x0` |

## 刷写

```sh
pip install esptool
# 首次安装和升级都是这一条
esptool --chip esp32s3 --port /dev/ttyACM0 --baud 921600 write_flash 0x0 feiyuos-v0.7-cardputer-adv.bin
```

Windows 上端口一般是 `COMx`，macOS 上是 `/dev/cu.usbmodem*`。刷写不会动 TF 卡和板载存储分区，设备上的配置、程序和对话记录都还在。也可以在 M5Burner 里搜「FeiyuOS」直接烧录（只有固件，卡上资源仍需解压 sd.zip）。

从 v0.6 及更早升级：v0.6.1 改过分区表，务必刷上面的完整镜像（`0x0`），不要只刷程序部分。

## 拷卡上资源

`sd.zip` 里只有 `vat/` 下的资源文件，解压到卡上只会新增或替换这几个文件，卡上原有的配置、程序和对话记录不受影响：

```sh
# macOS（卡名按实际改）/ Linux
unzip -o feiyuos-v0.7-sd.zip -d /Volumes/卡名
```

Windows：右键「全部解压缩」，目标选 TF 卡根目录。**macOS 不要用访达把 `vat` 文件夹直接拖到卡上**：遇到同名文件夹时访达默认是「替换」，会删掉卡上原有的 `vat`；要拖的话按住 Option 选「合并」。

## 第一次开机

固件里**不含任何 Key**。开机后进入设置页，同时开热点 `VAT-XXXX`：

1. 选 Wi-Fi、输入密码（只支持 2.4 GHz）。也可以在设置页选「手机设置（扫码）」，用手机填。
2. 填 Key（设置页「Key」，或手机扫码填）。**必需的只有前两个**，可选的不填也能用，只是少了对应功能：
   - **语音识别 Key（千问）**，必需：[阿里云百炼](https://bailian.console.aliyun.com/)开通模型服务，在「API-KEY」页创建，选北京地域（语音模型 `qwen3-asr-flash`，按音频时长计费，新账号有免费额度）。
   - **Agent Key（DeepSeek）**，必需：[DeepSeek 开放平台](https://platform.deepseek.com/)注册、充值，在「API keys」页创建。联网搜索也用它。
   - **高德 Key**，可选（不填只是不能查位置、附近、天气、路线）：[高德开放平台](https://console.amap.com/)创建应用、添加 Key，服务平台选「Web 服务」。
   - **接口令牌**，可选（比如 GitHub），不用事先填：第一次用时设备会弹出输入框，令牌只发给那个网站。
3. 建议插一张 TF 卡：程序、扩展包、长对话、完整输出、空调码库、开机动画和吉祥物都存在卡上。

Key、Wi-Fi 密码和接口令牌以明文保存在设备上，只在可信网络里使用，见 [SECURITY](https://github.com/hedykan/FeiyuOS/blob/main/SECURITY.md)。

## 说明

- 完整说明（安装、配置、界面、按键）见 [README](https://github.com/hedykan/FeiyuOS/blob/main/README.md)，更新细节见 [CHANGELOG](https://github.com/hedykan/FeiyuOS/blob/main/CHANGELOG.md)。
- 程序和扩展包的写法见 [程序文档](https://github.com/hedykan/FeiyuOS/blob/main/docs/PROGRAMS.zh-CN.md)；在线目录在仓库的 `packages/`，`tools/pkg_index.py` 生成。
- 用自建的 ESP-IDF 库编译，见 `firmware/README.md`。用官方板卡包自己编也能跑，但空闲内存少三四十 KB。
- 开机动画和吉祥物是社区鲸鱼娘的像素二创，不在 MIT 授权范围内，见 `assets/boot/NOTICE.md`、`assets/mascot/NOTICE.md`。
- 已知问题：HTTPS 不校验服务器证书（令牌只发给录入时的网站，下载的程序靠 SHA-256 校验）；开着蓝牙时最大连续内存块约 31 KB，画布动画的整屏缓冲可能分配不到，会直接画在屏幕上，略有闪烁。
