肥鱼 OS v0.6.1：大肥鱼会用蓝牙了——扫附近的设备、广播信标、连设备读数据，还能当蓝牙键盘往电脑里打字；程序能读陀螺仪和 GPS 的实时数据；开机空闲内存多出三成。

## 新增

- **蓝牙**（默认关闭，设置 → 蓝牙打开，重启生效）：
  - 「扫一下附近的蓝牙设备」：列出名字、信号强弱、厂商（Apple、小米……）、服务；还能把每条广播记到卡上，拿去做分析。
  - 「用蓝牙广播 iBeacon」：广播名字、自定义数据或 iBeacon。
  - 连接蓝牙设备，读写它的数据、订阅通知（心率带、温度计、自己做的单片机都行）；通知、信号强度、附近设备数都能给程序实时用。
  - **蓝牙键盘**：说「蓝牙键盘配对」，在电脑的蓝牙设置里选 FeiyuOS；之后说「在电脑上输入 hello world」「在电脑上按 cmd+space」就会打进电脑。只能打英文、数字和符号（中文靠电脑的输入法）；每次打字都要确认，确认框里能看到要打的内容；只在配对窗口里接受新电脑。
  - 配对成功、超时，记录写完、广播结束，屏幕底部都会提示。
- **实时数据流**：程序能每帧读陀螺仪、加速度、姿态角和 GPS 位置，写跟着设备倾斜滚动的小球这类程序有了数据来源（画布每帧计算留到下个版本）。
- **省内存**：重新编译底层库，开机空闲内存 110 → 147 KB，最大连续块 43 → 78 KB；开着蓝牙也还剩约 88 KB。
- **发布文件更简单**：一个固件、一个卡上资源包（sd.zip），解压到卡根目录就行。

## 下载哪个文件

| 文件 | 用途 | 写入地址 / 卡上位置 |
|:--|:--|:--|
| `feiyuos-v0.6.1-cardputer-adv.bin` | 固件，首次安装和升级都用它（引导程序 + 分区表 + 程序；不覆盖存储分区） | `0x0` |
| `feiyuos-v0.6.1-sd.zip` | TF 卡资源：开机动画、吉祥物、空调码库 | 解压到 TF 卡根目录 |
| `SHA256SUMS.txt` | 校验和 | — |

## 刷写

```sh
pip install esptool
# 首次安装和升级都是这一条
esptool --chip esp32s3 --port /dev/ttyACM0 --baud 921600 write_flash 0x0 feiyuos-v0.6.1-cardputer-adv.bin
```

Windows 上端口一般是 `COMx`，macOS 上是 `/dev/cu.usbmodem*`。刷写不会动 TF 卡和板载存储分区，设备上的配置、程序和对话记录都还在。也可以在 M5Burner 里搜「FeiyuOS」直接烧录（只有固件，卡上资源仍需解压 sd.zip）。

**从 v0.6 及更早升级**：这一版改了分区表（程序分区 3.2 → 6.4 MB），务必刷上面的完整镜像（`0x0`）；不要只刷程序部分。板载存储的位置没变，配置都还在。

## 拷卡上资源

`sd.zip` 里只有 `vat/` 下的资源文件，解压到卡上只会新增或替换这几个文件，卡上原有的配置、程序和对话记录不受影响：

```sh
# macOS（卡名按实际改）/ Linux
unzip -o feiyuos-v0.6.1-sd.zip -d /Volumes/卡名
```

Windows：右键「全部解压缩」，目标选 TF 卡根目录。**macOS 不要用访达把 `vat` 文件夹直接拖到卡上**：遇到同名文件夹时访达默认是「替换」，会删掉卡上原有的 `vat`；要拖的话按住 Option 选「合并」。

## 第一次开机

固件里**不含任何 Key**。开机后进入设置页，同时开热点 `VAT-XXXX`：

1. 选 Wi-Fi、输入密码（只支持 2.4 GHz）。也可以在设置页选「手机设置（扫码）」，用手机填。
2. 填语音识别 Key（通义千问）和 Agent Key（DeepSeek）；位置服务需要高德 Key（可选）。
3. 建议插一张 TF 卡：长对话、完整输出、程序与触发、空调码库、开机动画和吉祥物都存在卡上。

Key、Wi-Fi 密码以明文保存在设备上，只在可信网络里使用，见 [SECURITY](https://github.com/hedykan/FeiyuOS/blob/main/SECURITY.md)。

## 说明

- 用自建的 ESP-IDF 库编译（内核与堆的代码放 flash、只带蓝牙控制器、TLS 发送缓冲 4 KB 等），见 `firmware/README.md`。用官方板卡包自己编也能跑，但空闲内存少三四十 KB，开着蓝牙会很紧。
- 开机动画和吉祥物是社区鲸鱼娘的像素二创，不在 MIT 授权范围内，见 `assets/boot/NOTICE.md`、`assets/mascot/NOTICE.md`。
- 已知问题：开着蓝牙时最大连续内存块约 31 KB，画布需要的整屏缓冲可能分配不到（会提示内存不足）；连接的设备是电脑（Linux）时，对方可能反过来探测肥鱼的键盘服务并断开连接，订阅的通知断开后不会自动重连；128 位 UUID 的服务列不出特征（知道 UUID 时可以直接读写）。长时间运行后内存碎片会变多，正在排查。
- 下个版本（v0.6.2）：界面动画与分条渲染、顶栏信息、画布每帧计算（程序的 `set` 和循环）、内存泄漏与碎片。
