肥鱼 OS 第一个公开版本。跑在 M5Stack Cardputer Adv 上（可选 Cap LoRa-1262），按住 Enter 说一句话，大肥鱼（DeepSeek）调度设备上的各种能力。

## 这个版本能做什么

- **一句话办事**：位置、附近搜索、天气、路线（步行 / 驾车 / 骑行 / 电动车 / 公交，带大约时间，高德）；联网搜索；红外遥控电视；屏幕显示大字、二维码、图片；灯、提示音、定时提醒；SSH 连主机执行命令、接入 tmux，启动 Codex / Claude / Pi。
- **组合成程序**：几件事写成一段程序（`prog://`）存在卡上，可以互相调用、传参数，定时或开机自动运行（`trigger://`）。需要确认的步骤在保存时确认一次。
- **右下角的像素大肥鱼**：随任务状态变化（素材为二创，见 `assets/mascot/NOTICE.md`）。

完整说明见 [README](https://github.com/hedykan/FeiyuOS/blob/main/README.zh-CN.md) 和 [更新记录](https://github.com/hedykan/FeiyuOS/blob/main/CHANGELOG.md)。本版本在 v0.5.3 之外还包含两处界面修复：详情页显示完整回复、吉祥物不再挡住选中行。

## 下载哪个文件

| 文件 | 用途 | 写入地址 |
|:--|:--|:--|
| `feiyuos-v0.5.3-cardputer-adv.bin` | 首次安装（引导程序 + 分区表 + 程序；不覆盖设备上的存储分区） | `0x0` |

## 刷写

```sh
pip install esptool
# 首次安装
esptool --chip esp32s3 --port /dev/ttyACM0 --baud 921600 write_flash 0x0 feiyuos-v0.5.3-cardputer-adv.bin
# 升级
esptool --chip esp32s3 --port /dev/ttyACM0 --baud 921600 write_flash 0x10000 feiyuos-v0.5.3-app.bin
```

Windows 上端口一般是 `COMx`，macOS 上是 `/dev/cu.usbmodem*`。刷写不会动 TF 卡和板载存储分区，设备上的配置、程序和对话记录都还在。

## 第一次开机

固件里**不含任何 Key**。开机后进入设置页，同时开热点 `VAT-XXXX`：

1. 在键盘上选 Wi-Fi、输入密码（只支持 2.4 GHz）。
2. 填语音识别 Key（通义千问）和 Agent Key（DeepSeek）；位置服务需要高德 Key（可选）。可以在设备上填，也可以用手机扫设置页的二维码填。
3. 建议插一张 TF 卡：长对话、完整输出、程序与触发、吉祥物都存在卡上。

Key、Wi-Fi 密码以明文保存在设备上，只在可信网络里使用，见 [SECURITY](https://github.com/hedykan/FeiyuOS/blob/main/SECURITY.md)。

## 说明

- 用自建的 ESP-IDF 库编译（TLS 发送缓冲 16 KB → 4 KB，HTTPS 握手时多留出内存）。自己用官方板卡包编译也能跑，但内存余量会小一些，见 `firmware/README.md`。
- 还没有的：空调红外（在做，下个版本）、蓝牙。
