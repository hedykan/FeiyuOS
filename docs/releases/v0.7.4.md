肥鱼 OS v0.7.4：提示词减半、5 秒开机、代码模式、统一的地址。大肥鱼每次对话要读的说明少了一半，回答更快也更省；开机从将近一分钟缩到几秒；临时要算点什么、调点什么，可以直接跑一段代码，要确认的事在设备上当场问你。

## 新增

- **提示词约减半**：各扩展包的完整用法不再每次都塞给模型，只给一行索引，用到时再查。整体任务平均每个少读三分之一以上的 token，理解指令的准确度不变。
- **开机 5 秒**：从 49 秒左右缩到 5 秒左右，卡上的同步放到后台慢慢做。
- **代码模式**：让大肥鱼「算一下」「把这几个值读出来比一比」这类一次性的事，它会写一段 Lua 直接跑，不再先存成程序。代码里要写入或联网时，设备当场弹出 Y / N / A（全部）问你，Esc 或 60 秒不答算拒绝。
- **地址统一**：本机的部件和通道（屏幕、灯、电量、LoRa、蓝牙、WiFi、红外……）都在 `device://local/…` 下，偏好设置都在 `settings://…`，事件都是 `来源://event/名称`。写扩展包和程序的人有了一套固定写法（扩展包指南第 5 章），模型也少猜错地址。
- **没接的硬件不打扰**：没接 LoRa、GPS，或没填高德 Key 时，相关说明不进提示词，问到时会告诉你「未接上」。

## 已知的限制

- 单个程序约 7 KB 源码仍是上限（Lua 虚拟机 48 KB）；程序之间还不共用数据。
- 旧写法（`ble://`、`ir://`、`lora://`、`wifi://`、`pkg://install/名字` 等）不再认，会直接报错并提示新写法。
- 电池开着又插着 USB 时，TF 卡在大量写入时可能超时，最坏会写坏卡上的文件系统。长时间插着电脑跑任务时，建议把电池开关关掉。

## 刷写

```sh
pip install esptool
# 首次安装和升级都是这一条
esptool --chip esp32s3 --port /dev/ttyACM0 --baud 921600 write_flash 0x0 feiyuos-v0.7.4-cardputer-adv.bin
```

Windows 上端口一般是 `COMx`，macOS 上是 `/dev/cu.usbmodem*`。刷写不会动 TF 卡和板载存储分区，设备上的配置、程序和对话记录都还在。这个版本只在 GitHub 发布，M5Burner 上仍是 v0.7.1。

从 v0.7 ~ v0.7.3 升级只需刷固件，卡上资源没有变化。第一次开机会把卡上已保存的程序、已确认的权限、触发和面板应用里的旧地址改成新写法（只做一次）；你自己记下来的地址（比如 `ble://`、`ir://`、`lora://`）要换成 `device://local/ble/` 这类新写法，对照表见扩展包指南第 5 章。从 v0.6 及更早升级，先看 [v0.7 的说明](https://github.com/hedykan/FeiyuOS/releases/tag/v0.7)（程序改用 Lua，旧 JSON 程序需要翻译）。

## 拷卡上资源

`sd.zip` 里只有 `vat/` 下的资源文件，解压到卡上只会新增或替换这几个文件，卡上原有的配置、程序和对话记录不受影响：

```sh
# macOS（卡名按实际改）/ Linux
unzip -o feiyuos-v0.7.4-sd.zip -d /Volumes/卡名
```

Windows：右键「全部解压缩」，目标选 TF 卡根目录。**macOS 不要用访达把 `vat` 文件夹直接拖到卡上**：遇到同名文件夹时访达默认是「替换」，会删掉卡上原有的 `vat`；要拖的话按住 Option 选「合并」。

## 第一次开机

固件里**不含任何 Key**。开机后进入设置页，同时开热点 `VAT-XXXX`：

1. 选 Wi-Fi、输入密码（只支持 2.4 GHz）。也可以在设置页选「手机设置（扫码）」，用手机填。
2. 填 Key（设置页「Key」，或手机扫码填）。**必需的只有前两个**，可选的不填也能用，只是少了对应功能：
   - **语音识别 Key（千问）**，必需：[阿里云百炼](https://bailian.console.aliyun.com/)开通模型服务，在「API-KEY」页创建，选北京地域。
   - **Agent Key（DeepSeek）**，必需：[DeepSeek 开放平台](https://platform.deepseek.com/)注册、充值，在「API keys」页创建。
   - **高德 Key**，可选（不填只是不能查位置、附近、天气、路线）：[高德开放平台](https://console.amap.com/)创建应用、添加 Key，服务平台选「Web 服务」。
   - **接口令牌**，可选（比如 GitHub），不用事先填：第一次用时设备会弹出输入框，令牌只发给那个网站。
3. 建议插一张 TF 卡：程序、扩展包、长对话、完整输出、空调码库、开机动画和吉祥物都存在卡上。

Key、Wi-Fi 密码和接口令牌以明文保存在设备上，只在可信网络里使用，见 [SECURITY](https://github.com/hedykan/FeiyuOS/blob/main/SECURITY.md)。
