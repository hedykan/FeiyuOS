肥鱼 OS v0.6：大肥鱼能在屏幕上画东西、做小应用了，开机有了入场动画，内存也省出来一截。

## 新增

- **画布**：说「画一个旋转的椭圆」「画个电量表，显示现在的电量」，大肥鱼就在屏幕上画出来。绘制指令和 M5GFX 一样（线、矩形、圆、椭圆、三角形、圆弧、文字、二维码、进度条、卡上图片），可以旋转、做循环动画，也能绑定数据定时刷新。整张画好再显示，不会一块一块地出现。
- **面板与本地应用**：大肥鱼可以画带选项的面板，用 `;` `.` 选、`Enter` 确定，选择结果还能触发程序；常用的面板、画布能存成本地应用，`Fn+A` 打开。
- **开机动画**：挂卡前冒气泡，之后像素大肥鱼从随机一侧入场——走进来、跳下来或从底下爬出来——再等着开机完成；进度条是一条水面，前头游着一条小鱼。
- **多段录音**：Agent 页按住 `Fn+Enter` 说一段，可以说好几段攒成草稿，单击 `Enter` 一起发送。
- **帮助页能选**：`Fn+H` 里选中一行按 `Enter`，看当前值、怎么说和完整用法。
- **空调换码能前后选**：试码时可以说「上一套」「下一套」「第 5 套」。
- **网页接口加了令牌**：同一局域网里的人不能再随便读设置、改 Key。令牌在设置页「网页令牌」里看，也能扫码登录。
- **省内存**：大块内存统一登记、借完就还，TLS 缓冲按实际大小分配；对话记忆长度可以在设置页调（短 32 / 中 64 / 长 96 KB）。

## 修正

- 离线开机后设置页搜不到 WiFi。
- SSH 页闪烁、打字被吞、草稿另起一行。
- 多段录音的草稿看不到新说的那段。
- 大模型连续出错时会把一串内部标记当成回复显示出来。

## 刷写

```sh
pip install esptool
# 首次安装
esptool --chip esp32s3 --port /dev/ttyACM0 --baud 921600 write_flash 0x0 feiyuos-v0.6-cardputer-adv.bin
# 升级
esptool --chip esp32s3 --port /dev/ttyACM0 --baud 921600 write_flash 0x10000 feiyuos-v0.6-app.bin
```

Windows 上端口一般是 `COMx`，macOS 上是 `/dev/cu.usbmodem*`。刷写不会动 TF 卡和板载存储分区，设备上的配置、程序和对话记录都还在。也可以在 M5Burner 里搜「FeiyuOS」直接烧录（只有固件，动画、吉祥物和码库仍需拷到卡上）。

从 v0.5.x 升级：网页接口从这一版起要令牌，开机时令牌会在 USB 串口打印一次，也可以在设置页「网页令牌」查看。

## 第一次开机

固件里**不含任何 Key**。开机后进入设置页，同时开热点 `VAT-XXXX`：

1. 选 Wi-Fi、输入密码（只支持 2.4 GHz）。也可以在设置页选「手机设置（扫码）」，用手机填。
2. 填语音识别 Key（通义千问）和 Agent Key（DeepSeek）；位置服务需要高德 Key（可选）。
3. 建议插一张 TF 卡：长对话、完整输出、程序与触发、空调码库、开机动画和吉祥物都存在卡上。

Key、Wi-Fi 密码以明文保存在设备上，只在可信网络里使用，见 [SECURITY](https://github.com/hedykan/FeiyuOS/blob/main/SECURITY.md)。

## 说明

- 用自建的 ESP-IDF 库编译（TLS 发送缓冲 16 KB → 4 KB，HTTPS 握手时多留出内存）。自己用官方板卡包编译也能跑，但内存余量会小一些，见 `firmware/README.md`。
- 开机动画和吉祥物是社区鲸鱼娘的像素二创，不在 MIT 授权范围内，见 `assets/boot/NOTICE.md`、`assets/mascot/NOTICE.md`。
- 画布现在做不了跟着陀螺仪实时滚动的小球这类需要计算和状态的效果，计划在后续版本加入。还没有的：蓝牙。下个版本（v0.6.1）做界面动画和顶栏信息。
