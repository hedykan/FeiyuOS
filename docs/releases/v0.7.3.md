肥鱼 OS v0.7.3：稳定和内存。让大肥鱼写程序、跑程序、读长输出时，设备的内存余量明显变大，任务之间不再越用越少；后台跑的程序失败了能看见。

## 新增

- **内存余量更大**：在设备上让大肥鱼写一个 6 KB 的程序，空闲内存最低点从 11 KB 提到 24 KB；直接运行这个程序从十几 KB 提到 28–32 KB。全量验收里整轮最低点 46 KB（v0.7.2 是 36 KB）。
- **越用越少的问题没了**：以前跑几个任务后空闲内存从 125 KB 一路降到 87 KB，内存碎了以后同一个程序会编译失败；现在连写三遍工具箱，空闲内存都回到 117–122 KB。
- **读长输出、程序调程序更稳**：读几百 KB 的远端输出、一个程序调用另一个程序时，内存最低点不再忽高忽低。
- **后台失败看得见**：定时、开机或被事件触发的程序失败时会发出 `prog://event/failed` 事件，可以写个触发去通知你；状态栏新增「后台失败」，某个程序连续失败 3 次以上时显示。默认顶栏已加上；改过顶栏的，在设置里加上「后台失败」。
- **少做无用功**：没有终端时让大肥鱼「看终端」，它不会再连着观察好几轮；同样的失败出现两次就停下来告诉你。

## 已知的限制

- 单个程序约 7 KB 源码仍是上限（Lua 虚拟机 48 KB）；程序之间还不共用数据。
- 读几百 KB 的远端输出比 v0.7.2 慢几秒（换来稳定的内存）。
- 设备的时间没对上时，运行记录里的时间显示为 `--:--`。
- 电池开着又插着 USB 时，TF 卡在大量写入时可能超时，最坏会写坏卡上的文件系统（开发时遇到过一次）。长时间插着电脑跑任务时，建议把电池开关关掉。

| 文件 | 用途 | 写入地址 / 卡上位置 |

## 刷写

```sh
pip install esptool
# 首次安装和升级都是这一条
esptool --chip esp32s3 --port /dev/ttyACM0 --baud 921600 write_flash 0x0 feiyuos-v0.7.3-cardputer-adv.bin
```

Windows 上端口一般是 `COMx`，macOS 上是 `/dev/cu.usbmodem*`。刷写不会动 TF 卡和板载存储分区，设备上的配置、程序和对话记录都还在。这个版本只在 GitHub 发布，M5Burner 上仍是 v0.7.1。

从 v0.7 ~ v0.7.2 升级只需刷固件，卡上资源没有变化；程序的使用统计会在第一次开机时自动转换。从 v0.6 及更早升级，先看 [v0.7 的说明](https://github.com/hedykan/FeiyuOS/releases/tag/v0.7)（程序改用 Lua，旧 JSON 程序需要翻译）。

## 拷卡上资源

`sd.zip` 里只有 `vat/` 下的资源文件，解压到卡上只会新增或替换这几个文件，卡上原有的配置、程序和对话记录不受影响：

```sh
# macOS（卡名按实际改）/ Linux
unzip -o feiyuos-v0.7.3-sd.zip -d /Volumes/卡名
```

Windows：右键「全部解压缩」，目标选 TF 卡根目录。**macOS 不要用访达把 `vat` 文件夹直接拖到卡上**：遇到同名文件夹时访达默认是「替换」，会删掉卡上原有的 `vat`；要拖的话按住 Option 选「合并」。

## 第一次开机

固件里**不含任何 Key**。开机后进入设置页，同时开热点 `VAT-XXXX`：

1. 选 Wi-Fi、输入密码（只支持 2.4 GHz）。也可以在设置页选「手机设置（扫码）」，用手机填。
2. 填 Key（设置页「Key」，或手机扫码填）。**必需的只有前两个**，可选的不填也能用，只是少了对应功能：
   - **语音识别 Key（千问）**，必需：[阿里云百炼](https://bailian.console.aliyun.com/)开通模型服务，在「API-KEY」页创建，选北京地域。
   - **Agent Key（DeepSeek）**，必需：[DeepSeek 开放平台](https://platform.deepseek.com/)注册、充值，在「API keys」页创建。
   - **高德 Key**，可选（不填只是不能查位置、附近、天气、路线）：[高德开放平台](https://console.amap.com/)创建应用、添加 Key，服务平台选「Web 服务」。
   - **接口令牌**，可选（比如 GitHub），不用事先填：第一次用时设备会弹出输入框，令牌只发给那个网站。
3. 建议插一张 TF 卡：程序、扩展包、长对话、完整输出、空调码库、开机动画和吉祥物都存在卡上。

Key、Wi-Fi 密码和接口令牌以明文保存在设备上，只在可信网络里使用，见 [SECURITY](https://github.com/hedykan/FeiyuOS/blob/main/SECURITY.md)。
