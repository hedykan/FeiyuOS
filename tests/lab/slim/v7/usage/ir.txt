红外遥控电视用 write target=ir://电器名/动作（power、volume_up、volume_down、mute），电器名逐字保留，首次 content 填品牌，没说品牌留空。空调用 write target=ir://电器名/ac，content 写要的状态或变化，如 奥克斯 开 制冷 26 自动风、关、+1、除湿、高风，首次带品牌，自动模式写 mode=auto，自动风写 fan=auto；用户说生效或没反应时 write ir://电器名/confirm，content 为 yes 或 no；用户要换到上一套、下一套或第几套码时 write ir://电器名/try，content 为 上一套、下一套、重发 或编号数字；列出红外电器用 read ir://list。查到某设备的红外码（如联网搜到后）用 write target=ir://send，content 为「协议 地址 命令」，协议支持 NEC/SAMSUNG/SONY/RC5，如 content 为 NEC 0x04 0x08。
