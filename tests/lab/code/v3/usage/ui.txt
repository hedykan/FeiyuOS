即时界面（ui://）：要给用户看一个小面板、或让用户在几个选项里选一个时用。write target=ui://panel/名字，content 为 JSON 对象：title 标题；lines 文字行数组（最多 12 行）；choices 选项数组（最多 8 个）；source 可选，打开期间定时刷新 lines，写成 read 或 exec 加目标，或 tool 加 arguments（与工具调用同形），再加 every（如 30s，至少 10 秒）。用户选定后 read ui://panel/名字 取结果，或建触发监听 ui://panel/名字（{event.choice}）。存成可反复打开的本地应用：write ui://apps/名字（content 同上）；打开 write ui://apps/名字/open；列出 read ui://apps；删除 write ui://apps/名字/delete。设备上 Fn+A 打开程序页，程序和本地应用都列在那里。自由绘图用 write target=ui://canvas/名字，content 为 JSON 对象，ops 为绘制指令数组，每条写成 [指令名, 参数…]，指令与 M5GFX 同名同参：fillScreen、drawPixel、drawLine、drawFastHLine、drawFastVLine、drawRect、fillRect、drawRoundRect、fillRoundRect、drawCircle、fillCircle、drawEllipse、fillEllipse、drawTriangle、fillTriangle、drawArc、fillArc（x y 内半径 外半径 起角 止角）、drawBezier、drawGradientLine（两色）、drawString（文字 x y，可加选项 size 1 到 4、color、datum 如 middle_center）、drawQr（文字 x y 宽）、drawImage（/vat/ 下图片 x y，最多一张）、progressBar（x y 宽 高 百分比 颜色 底色），颜色写 #RRGGBB 或 white red cyan 等；屏幕 240×135，最多 64 条；旋转用 [rotate, 角度, 中心x, 中心y] 作用于其后的图形，[rotate, 0, 0, 0] 取消；动画在 content 顶层加 animate：every 每帧间隔如 100ms（至少 33ms）、frames 帧数（0 表示一直到关闭）、step 每帧增量，参数里的 {t} 换成 帧序号乘 step（{t} {1} {1#} 这类占位符在 JSON 里写成带引号的字符串），例如椭圆原地旋转：ops 先 [rotate, {t}, 120, 67] 再 [fillEllipse, 120, 67, 50, 20, cyan]，animate 为 every 100ms、frames 0、step 10。变量动画：顶层加 vars（初值对象，如 x 为 20、vx 为 6）和 update（每帧先执行的一段 Lua 代码，如 x = x + vx  if x > 220 or x < 20 then vx = -vx end；可用 vars 里的变量、t 帧序号乘 step、math，以及 vat.stream 读传感器，不能调用其他能力），参数里写 {x} 取变量值；有 update 没 animate 时每 33ms 一帧直到关闭。可加 source 定时刷新，参数里的 {1} {2} 换成结果的第 1、2 行，{1#} 换成第 1 行里的第一个数字（用于大数字和进度条）。画布也能存成应用（ui://apps/名字，content 同上）。
