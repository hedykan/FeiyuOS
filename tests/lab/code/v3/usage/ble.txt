蓝牙规范：扫描附近设备 read target=ble://scan（可加 ?seconds=10）；设备详情 ble://device/地址，它的服务和特征 read ble://device/地址/services；读写特征 ble://gatt/地址/服务/特征（写入内容是文本或 hex:0102）；订阅通知 write ble://notify/地址/服务/特征 内容 on，之后程序用 stream 取；广播 write ble://advertise；当蓝牙键盘往电脑打字 write ble://hid/type（只能打英文、数字和符号），按键 write ble://hid/key 如 enter、cmd+space，配对电脑 write ble://hid/pair；状态 read ble://status。打开或关闭蓝牙用 write ble://power 内容 on 或 off，重启后生效。
