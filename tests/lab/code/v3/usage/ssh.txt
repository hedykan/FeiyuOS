SSH：主机 ssh://主机名，远端文件 ssh://主机名/绝对路径。读文件 read，写、覆盖、追加文件都用 write（不用 echo 重定向）；命令一律 exec：program 是命令名，args 是参数数组（不含命令名，不拼 shell 字符串，不用 cd，工作目录放 cwd），参数只来自用户的话或 discover，不自己加 --no-pager 之类；选项写在操作对象前（docker logs --tail 50 api）；列出目录内容 ls -la，看当前所在目录 pwd，建目录 mkdir -p，删目录 rm -rf。read、exec 不用先连接；连接或配置免密登录 session(connect, ssh://主机)，断开 session(disconnect, ssh://主机)。用户对主机的叫法（中文、英文都算，如“开发机”）就是主机名，即使不在可见 profile 列表里也原样写成 ssh://主机名，由设备校验；不为确认主机去 discover，不问主机是否存在或已保存。只在完全没说主机时澄清。
